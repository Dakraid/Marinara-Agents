# SCOUT-REPORT: Marinara-Agents full-package anatomy (card-editor graduation)

## Architecture
`packages/<id>/`: manifest.json + agents.json (+ generated client.js/server.mjs + `src/engine/...` owned sources for feature packages). `artifacts/*.zip` + `catalog/**` are GENERATED (never hand-edit). Builders: agent-only → `scripts/build-agent-catalog.mjs` (skips any package with server/client entrypoints, L60-62); feature → `scripts/build-feature-packages.mjs` (esbuild against `MARINARA_ENGINE_ROOT`; feature table :337-695; manifest emission :1797-1920 incl. capabilityApi+builtAgainst from `engine-boundary.json`, files hashes, deterministic zip, catalog push).

## Key facts
- **No package registers into any selection action bar** today (only engine CSS chrome strings bundled in noodle/slurp2). Character-card "Run Card Editor" button is engine-rendered from the agent definition (`scripts/catalog-package-guidance.mjs:5-8`).
- Connection pickers in packages: LTM (`MemorySettings.tsx` `GET /api/connections`), World Maps (`use-spatial-context.ts` → `/connections`, package-api `API_BASE="/api"`). Prompt presets = `agents.json` `promptTemplates[]` (illustrator ids comic-page/colored-manga/...; localized `agents.<id>.promptTemplates.<tid>.{name,description}`).
- Character loading package-side: `modern-life-sim`/`gacha-forge` paginate `/api/characters/catalog?limit&offset&sort=name-asc`, fetch `/api/characters/:id`, personas `/api/characters/personas/*`.
- Manifest v2 requires exact `builtAgainst.engineVersion` inside declared engine range (catalog-lanes provenance); `engine-boundary.json` `privateEngineImports` must stay `[]` (no engine internals in package code).
- Minor/major bump REQUIRES matching newest CHANGELOG entry (`packages/<id>/CHANGELOG.md`, newest-first `## x.y.z — YYYY-MM-DD`, ≤1000 chars/entry, `[highlight]`/`[quiet]` markers).
- `npm run check` = Prettier+ESLint on `packages/**/src`, `scripts`, `tests` only.
