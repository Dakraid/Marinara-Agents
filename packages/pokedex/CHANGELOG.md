# Pokédex Scanner release notes

## 0.1.0 — 2026-10-02

First development build. Scans Pokémon on first encounter and renders the Pokédex entry card in the chat, tracks the active harem, pregnancies, and recent encounters per chat, and adds a tracker panel with the full scanned collection plus correction actions. In-chat scan cards need Marinara Engine 2.4.6 with Capability API 1.66; on older engines the tracker state and panel still work.
