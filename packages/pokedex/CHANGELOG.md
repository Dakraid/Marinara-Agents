# Pokédex Scanner release notes

## 0.1.0 — 2026-10-02

First development build. Scans Pokémon on first encounter and renders the Pokédex entry card in the chat, tracks the active harem, pregnancies, and recent encounters per chat, and adds a tracker panel with the full scanned collection plus correction actions. In-chat scan cards require the matching Marinara Engine update; without it the tracker state and panel still work.
